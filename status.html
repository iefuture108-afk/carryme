🔧 Troubleshooting

If links aren't opening:

  • Check internet connection
  • Clear browser cache (Ctrl+Shift+Delete)
  • Try different browser (Chrome, Firefox, Safari)
  • Wait 1-2 minutes for Vercel to fully deploy
  • Check GitHub for latest commits

If images aren't showing:

  • Images are stored in repository root (not in /images folder)
  • File names are: "home decor.png", "Sofa cover.png", etc.
  • Update image paths in home-decor.html if needed
  • Check image permissions in GitHub

Custom domain setup (www.carryme.store):

  • Add domain to Vercel project settings
  • Update DNS settings at domain registrar
  • Point to: 76.76.19.21 (or Vercel's current IP)
  • Wait 24-48 hours for DNS propagation
