# 🚀 CarryMe Store

> **Smart. Stylish. Always With You.**

An AI-powered commerce platform built to help Indian sellers **Learn, Launch, Sell, and Scale**.

🌐 Live Demo:
- Website: https://carryme.store
- App: https://carryme-stores.streamlit.app/

---

# 🌟 Vision

CarryMe is building India's AI-powered commerce ecosystem for entrepreneurs, creators, and small businesses.

Our mission is to empower every seller with the tools, knowledge, and AI needed to build a successful business.
