# CarryMe - E-Commerce Platform for Indian Women Shoppers

🛍️ **CarryMe** is a modern e-commerce website designed specifically for Indian women, offering:
- **Home Appliances** - Quality kitchen and home products
- **Terracotta Jewelry** - Handcrafted traditional accessories
- **Kids Fashion** - Comfortable and trendy children's clothing
- **Home Decor** - Traditional and modern decoration items

## Features

✅ **SEO Optimized** - Built for Google rankings in India
✅ **Mobile Responsive** - Perfect on all devices
✅ **Indian-Focused** - Designed for Indian women shoppers
✅ **Fast Loading** - Optimized performance
✅ **Accessible Design** - Easy to navigate
✅ **Modern UI** - Professional e-commerce look
